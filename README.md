# ごはんきまった？

冷蔵庫の中身を管理しながら、今ある食材で作れる料理を提案・検索でき、作った料理の履歴を残せるアプリです。

## 使い方

`index.html` をブラウザで開くだけで使えます（GitHub Pages でも公開できます）。

- **冷蔵庫**：食材の追加・削除、量・分類、任意の賞味期限／消費期限、先に使いたい食材の優先指定、調味料の登録
- **レシピ提案**：ジャンルと「使っちゃいたい食材」を選ぶと、今ある食材で作れる料理を提案
- **レシピ検索**：料理名・食材で検索し、レシピをアプリの中で日本語で読めます
- **履歴**：作った料理を日付・使った食材つきで記録

## 注意

このページは静的なページのため、入力した内容は自動保存されません。ページを閉じると消えるので、残したい時は冷蔵庫タブの「ファイルに書き出す」を使ってください。
